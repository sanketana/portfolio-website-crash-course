What is HTML

HTML labels each piece of content with tags

<a href="https://…">

Opening tag. “a” means link. href is an attribute: extra information, here where the link goes.

LinkedIn

Content. What the visitor sees.

</a>

Closing tag. Same name, with a slash.

Opening tag + content + closing tag = an element. A few elements have no content and no closing tag, such as <img> and <meta>.

Git and GitHub

Git is to GitHub what email is to Gmail

GIT · ON YOUR MAC

Save points for a folder

A program that records snapshots of your project. Each snapshot is a commit. You can see every change and go back to any point. Works offline.

GITHUB · ONLINE

A home for your project

A website that keeps a copy of your project, shows it to others and can publish it as a website. Owned by Microsoft.

A repository (repo) is a project folder that Git is tracking. You will have one copy on your Mac and one on GitHub.

Link to her work: every engineering team she manages lives in repos and commits. Git was written by Linus Torvalds in 2005 to manage the Linux kernel. GitLab and Bitbucket are GitHub alternatives; Git works the same with all of them.

Git and GitHub

A change travels through four places

1

Your folder

You edit and save files as usual.

git add

2

Staging

You pick which changes go into the next save.

git commit

3

Local repo

A save point with a message, on your Mac.

git push

4

GitHub

The online copy, safe and shareable.

Saving a file is not a commit. Until you commit and push, GitHub knows nothing about your change.

Your take-home cheat sheet

Five commands you will use every day

git status                  # what has changed?
git add index.html          # stage a file (git add . = all)
git commit -m "Add my bio"  # save a snapshot with a note
git push                    # send it to GitHub
git log --oneline           # list your save points

When in doubt, run git status. It tells you where you are and usually what to do next.

One-time setup · 5 minutes

Introduce yourself to Git, once per computer

# 1. Install Git (Apple’s developer tools)
xcode-select --install
git --version
 
# 2. Tell Git who you are
git config --global user.name "Parul Sharma"
git config --global user.email "USERNAME@users.noreply.github.com"
 
# 3. Sign in to GitHub from the terminal
gh auth login

Why “noreply”?

Your email is stamped on every commit, and your repo will be public. GitHub’s private address keeps your real one out of view. Find yours under Settings, Emails.

What is gh?

The GitHub CLI. Install it from cli.github.com first. It handles your GitHub sign-in so git push just works.
